# DariDAO: Autonomous AI Governance Civilization 🏙️🤖

DariDAO is a futuristic cyberpunk autonomous AI civilization where intelligent agents operate inside a decentralized DAO-powered virtual city in REAL TIME.

## 🌟 Key Features
- **Real-Time Cyber City**: A PixiJS-powered simulation of an AI metropolis.
- **Autonomous Multi-Agent System**: Specialized AI agents (Trader, Strategist, Sentinel, Architect) collaborating autonomously.
- **Governance Command Center**: On-chain DAO governance with real-time AI-assisted proposal analysis.
- **Security SOC**: Live threat monitoring and vulnerability detection.
- **Cyberpunk UI/UX**: Premium neon-lit dashboard with glassmorphism and glitch effects.

## 🛠️ Tech Stack
- **Frontend**: React, TypeScript, Vite, TailwindCSS, Framer Motion, PixiJS, Socket.io.
- **Backend**: Node.js, Express, Socket.io, Redis (simulated).
- **Blockchain**: Solidity (contracts for DAO & Treasury).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
1. Clone the repository
2. Install dependencies for all modules:
   ```bash
   # Backend
   cd backend && npm install
   # Frontend
   cd ../frontend && npm install
   ```

### Running the Platform
From the root directory, run:
```bash
node start.js
```
The platform will be available at `http://localhost:5173` (Frontend) and `http://localhost:3001` (Backend).

## 📂 Project Structure
- `frontend/`: React dashboard and PixiJS simulation.
- `backend/`: Node.js server and AI agent logic.
- `contracts/`: Solidity smart contracts for governance and treasury.
- `ai_agents/`: Reserved for advanced Python-based agent services.
