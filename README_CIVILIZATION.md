# 🧠 AI Civilization - Autonomous Agent Simulation

A sophisticated AI civilization where autonomous agents with LLM-powered thinking systems create emergent social dynamics and complex behaviors.

## 🎯 Overview

This project creates a living AI civilization where agents:
- **Think autonomously** using LLM-powered reasoning
- **Follow complete decision cycles**: OBSERVE → THINK → DECIDE → ACT → REMEMBER  
- **Learn from experience** through advanced memory systems
- **Develop personalities** with unique archetypes and behaviors
- **Create emergent stories** through complex social interactions

## 🏗️ System Architecture

### **Core Intelligence Engine**
- **LLM Reasoning**: Agents use AI to generate human-like thoughts
- **Memory Systems**: Short-term, long-term, relationships, location knowledge
- **Personality Profiles**: Unique traits, archetypes, and decision styles
- **Dynamic Goals**: Adaptive motivations based on state and environment
- **External Data**: Market trends, environmental conditions, global events

### **Agent Types**
- **Warrior**: High aggression, defends territory and allies
- **Trader**: Cooperative, seeks profitable exchanges  
- **Explorer**: High curiosity, discovers new areas and resources
- **Diplomat**: High empathy, resolves conflicts through negotiation
- **Thief**: High greed, stealth-based resource acquisition
- **Healer**: High empathy, helps injured agents
- **Leader**: Balanced traits, coordinates civilization activities

### **Decision Making Cycle**
1. **OBSERVE**: Collect environmental data, nearby agents, resources
2. **THINK**: AI generates reasoning using personality and memory
3. **DECIDE**: Choose action based on AI output, not hardcoded rules
4. **ACT**: Execute decision on grid with consequences
5. **REMEMBER**: Store experience in memory for future decisions

## 🚀 Getting Started

### **Installation**
```bash
cd ai_civilization
pip install -r requirements.txt
```

### **Running the Application**
```bash
python app_autonomous.py
```

### **Access Points**
- **Autonomous Simulation**: http://localhost:5000/
- **Control Panel**: http://localhost:5000/control

## 🔮 Technical Architecture

### **Backend (Python)**
- **Flask** web framework
- **Socket.IO** for real-time communication
- **LLM Integration** for AI reasoning (simulated for now, ready for real LLM)
- **Async simulation** loop with autonomous agents

### **Frontend (HTML/JavaScript)**
- **Tailwind CSS** for responsive design
- **Real-time updates** via WebSocket
- **Thought bubble visualization** with confidence indicators
- **Environmental effects** for day/night and weather

### **Data Flow**
1. Agents observe environment and collect data
2. LLM reasoning engine processes information
3. Decisions made based on AI output
4. Actions executed with consequences
5. Experiences stored in memory systems
6. Updates broadcast via WebSocket to all interfaces
